# 📋 가상클라이언트 생성 & 레퍼런스 분석 자동화 프로세스 명세서 (1~4번 정식 규격 반영)

본 명세서는 가상클라이언트 생성부터 분석 스킬 발동, 브랜드 관련 레퍼런스(엄선된 정예 웰니스 롤모델) 사이트 분석(메뉴, 콘텐츠, 기능)까지의 3단계 파이프라인 자동화 체계를 정의한 공식 작업 지침서입니다.

## 📋 2. 3단계 자동화 프로세스 명세

### [Step 1] 가상클라이언트 완전체 마크다운(.md) 자동 생성 명세
- **목적**: 기획 문서 및 원본 소스 데이터를 종합하여 **1~4번과 100% 동일한 6대 대단원 완전체 마크다운 문서** 생성
- **소스 경로**: `C:\yyw\가상클라이언트 생성\` 루트 파일 및 `브랜드 가상클라이언트\` 폴더 내 파일 전량
- **생성 규칙**:
  1. 기존 `C:\yyw\가상 클라이언트 모음\가상클라이언트\` 내 기존 클라이언트(1~6번 및 기존 타깃)와 **중복 차단**
  2. 번호는 **`가상클라이언트_7` (7번)**부터 순차 부여
  3. **6대 대단원 필수 작성 (최소 5KB 이상)**:
     - `## 1. 가상 클라이언트` (프로젝트 주제, 제작 목적, 제공 자료, 적용 매체)
     - `## 2. 클라이언트 요구사항` (최소 5개 이상의 구체적 요구사항 표: 번호, 요청 내용, 관련 자료, 중요도)
     - `## 3. 정보 구조 (IA & 5대 영역 분석)` (주제, 부주제, 메뉴 5개, 5대 영역 상세, 사실/개념/절차 정보유형)
     - `## 4. 내비게이션 & 사용자 흐름 (User Flow)` (시작 화면, 5단계 이동 경로, 모달/팝업, 검색 및 위치 안내)
     - `## 5. 화면 구성 (레이아웃 & 와이어프레임)` (헤더, GNB, 1~8번 핵심 콘텐츠 상세 명세, 보조 콘텐츠, 푸터)
     - `## 6. 검토 결과` (누락 항목 0건 검증, 중복 항목 정리, 사용자 관점 개선점, 차별화 전략)
- **저장 위치**: `C:\yyw\가상 클라이언트 모음\가상클라이언트\가상클라이언트_{N}_{타깃명}.md` (단순 .txt 생성 금지)

---

### [Step 2] 분석 스킬 발동 & 작성 양식 맞춤 변환 명세
- **목적**: 생성된 가상클라이언트 완전체 문서를 `분석_스킬`의 5대 영역과 양식 규격에 맞춰 정밀 분석 보고서로 변환
- **소스 경로**: Step 1 생성 파일(`.md`) + `C:\yyw\md_skill\분석_스킬\SKILL.md` + `가상 클라이언트 기반 분석 결과 작성 양식.md`
- **저장 위치**: `C:\yyw\가상 클라이언트 모음\가상클라이언트 분석\가상클라이언트_{N}_{타깃명}_분석결과.md`

---

### [Step 3] 가상클라이언트 기준 브랜드 관련 레퍼런스 분석 명세
- **목적**: `브랜드 관련 레퍼런스` 폴더 내 엄선된 정예 웰니스/라이프스타일 롤모델 사이트를 각 가상클라이언트 관점에서 벤치마킹하여 "메뉴, 콘텐츠, 기능" 분석 결과 도출
- **소스 경로**: Step 2 분석 보고서 + `C:\yyw\브랜드 관련 레퍼런스\` 폴더 데이터 (`01_선별_수집결과_데이터.txt`, `02_선별_분류결과_데이터.md`, `03_선별_심층분석_보고서.md`)
- **출력 포맷 명세**:
  - **[메뉴 (Menu)]**: GNB 5대 계층 구조, 뎁스(Depth 3이내), 타깃별 이동 동선
  - **[콘텐츠 (Content)]**: 메인 카피라이팅, 에디토리얼 룩북/매크로 뷰, 원천 기술/알고리즘 스펙, 찐후기 & 신뢰 배지
  - **[기능 (Function)]**: 바이오피드백 데이터 UI, 타깃 액션 UI, Floating Sticky CTA Bar
- **저장 위치**: `C:\yyw\가상 클라이언트 모음\사이트 분석 결과\사이트분석결과_가상클라이언트_{N}_{타깃명}.md`
