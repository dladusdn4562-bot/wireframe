# SEUMIM(스밈) 통합 마스터 서비스 흐름도 명세서 (서비스 흐름도 병합)

---

## 📌 1. 마스터 서비스 흐름도 개요 (Service Flow Overview)

본 문서는 **스밈(SEUMIM) 척추·관절 바이오메카닉스 서포터 & D2C 라이프스타일 웰니스 플랫폼**의 62개 가상클라이언트(1~62번 전 직군) 서비스 흐름도를 심층 분석하고 교차 병합(Merge)하여 도출한 **최고의 통합 마스터 서비스 흐름도(Master Service Flowchart)** 명세서입니다.

- **브랜드/플랫폼명**: 스밈(SEUMIM) 통합 헬스케어 & 에르고노믹스 플랫폼
- **통합 서비스 아키텍처**:
  1. **Omni-Entry**: 62개 직군 선택 필터 ➔ 직업병 통계 공감 ➔ 3D 관절 하중 분산 검증
  2. **Zero-Friction Conversion**: 카카오 1-Click 10초 신청 + 시니어 080 무료 전화 다이얼러 듀얼 지원
  3. **30-Day Risk-Free Trial**: 30일간 현장 실착 후 불만족 시 100% 무료 반품 (왕복 배송비 0원)
  4. **B2B Bulk Pipeline**: 전국 협회, 병원, 스튜디오, 기업체 대량 시착 20~25% 제휴
  5. **Post-Care & Retention**: 직군별 10초 관절 리셋 루틴 + 마이페이지 1-Click 무료 반품/배송 추적
- **흐름도 설계 표준**: `ST-01` ~ `ST-14` 전 단계 표준화, 4대 마스터 Happy Path, 5대 예외/분기 처리 완비.

## 🚀 3. 4대 마스터 Happy Path 상세 시나리오

```text
[Happy Path 1: D2C 1-Click] ST-01(메인) ➔ ST-02(서포터) ➔ ST-03(테크) ➔ ST-07(신청모달) ➔ ST-08(접수완료) ➔ ST-12(체험관리)
[Happy Path 2: 정밀 핏 매칭] ST-01(메인) ➔ ST-04(후기) ➔ ST-06(사이즈모달) ➔ ST-09(안심보증) ➔ ST-07(신청) ➔ ST-08(완료)
[Happy Path 3: B2B 단체 제휴] ST-01(메인) ➔ ST-05(스트레칭) ➔ ST-10(B2B제휴) ➔ 대량 견적 접수 ➔ B2B 납품
[Happy Path 4: 080 시니어 콜] ST-01(큰글씨 메인) ➔ 080 무료 다이얼(080-800-1234) ➔ 상담원 통화 ➔ ST-08(댁으로 발송)
```

### 📍 [Path 1] 직군 맞춤 D2C 1-Click 30일 무료 체험단 경로 (메인 고전환)
1. **진입 (`ST-01`)**: 사용자가 메인 랜딩에서 본인의 직군(예: 치과의사, 승무원, 물류 등)을 선택하고 3D 하중 분산 모식도를 확인.
2. **검증 (`ST-02`, `ST-03`)**: 0.1mm 심리스 일상복 핏과 공인 시험 기관(KATRI) 성능 성적서를 확인하여 제품 신뢰도 확보.
3. **전환 (`ST-07`)**: `[30일 무료체험 신청]` 클릭 후 카카오 1-Click 연동으로 10초 만에 배송지 자동 입력.
4. **완료 및 체험 (`ST-08`, `ST-12`)**: 주문 접수 알림톡 수령 후 댁/직장으로 제품 수령, 마이페이지에서 30일간 안심 실착.

### 📍 [Path 2] 1:1 체형 정밀 사이즈 매칭 & 무료 반품 경로 (맞춤 피팅)
1. **탐색 (`ST-04`)**: 동종 업계 종사자들의 실착 포토 후기와 평점 4.96점 검증.
2. **사이즈 매칭 (`ST-06`)**: 신체 치수(허리/가슴둘레)를 입력하여 1:1 추천 사이즈 확인.
3. **보증 확인 (`ST-09`)**: 30일 100% 무료 반품(왕복 배송비 0원) 안심 보증서 확인.
4. **신청 (`ST-07`, `ST-08`)**: 확정된 맞춤 사이즈로 무료 체험 신청 완료.

### 📍 [Path 3] 전국 협회/기업/스튜디오 B2B 단체 대량 제휴 경로 (B2B Bulk)
1. **루틴 소비 (`ST-05`)**: 업무 전후 실천하는 10초 관절 리셋 스트레칭 콘텐츠 확인.
2. **제휴 확인 (`ST-10`)**: 협회 및 스튜디오 강사 단체 20~25% 할인 및 단체 시착 키트 혜택 확인.
3. **수주 접수**: B2B 간편 견적 폼 작성 ➔ 전담 B2B 매니저 1:1 배정 및 샘플 키트 발송.

### 📍 [Path 4] 080 시니어 무료 전화 원터치 주문 경로 (Silver/Low-Digital)
1. **진입 (`ST-01`)**: 18px 큰 글씨 메인 화면에서 파크골프/시니어 비거리 15m 증가 및 관절 충격 흡수 확인.
2. **원터치 연결**: 화면 상단/하단의 `[📞 080-800-1234 통화료 무료]` 버튼 터치.
3. **주문 확정 (`ST-08`)**: 복잡한 결제 없이 전문 상담원과 통화로 성함/주소 확인 후 댁으로 즉시 무료 발송.
