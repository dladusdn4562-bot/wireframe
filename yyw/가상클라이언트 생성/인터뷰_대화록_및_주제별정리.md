## 1. 🛍️ 주제 1: 상품 구매 경로 및 앱 vs 웹 쇼핑 패턴

### ❓ 진행자 질문
> **"평소에 상품을 살 때 주로 어떤 경로(앱, 웹, 검색 등)로 들어가는 편이신가요?"**

### 💬 참가자별 답변 정리

* **👤 참가자 A (웹 기반 가격 비교형)**
  * **구매 방식**: 주로 **네이버**나 **쿠팡** 웹 사이트에서 검색 후 가격 비교.
  * **특징**: 어플보다는 웹 브라우저 탭을 여러 개 띄워놓고 최저가를 탐색하는 편.

* **👤 참가자 B (앱/카테고리 탐색형)**
  * **구매 방식**: 쇼핑 **어플(앱)**을 주로 사용.
  * **특징**: 앱에 들어가서 `카테고리 선택` -> `랭킹/리뷰 필터 적용` -> `원하는 가격대 설정` 순으로 상품 탐색. 원하는 브랜드가 명확할 때만 직접 브랜드 검색 후 진입.

* **👤 참가자 C (다중 앱 최저가 비교형)**
  * **구매 방식**: 여러 쇼핑 **어플을 동시에 실행**하여 비교.
  * **특징**: 최근 실행 탭에 여러 플랫폼을 띄워두고 "어디가 더 싼지", "사은품이 무엇인지", "영상 리뷰가 어떤지" 종합 비교한 뒤 **가장 저렴하고 혜택이 좋은 곳**에서 구매.

## 2. 🚨 주제 2: 쇼핑몰 앱/웹 UI/UX 사용 시 불편점 (페인포인트)

### ❓ 진행자 질문
> **"앱이나 웹으로 쇼핑하면서 사용하기 가장 불편했던 점이나 개선되었으면 하는 부분이 있었나요?"**

### 💬 참가자별 발언 정리

* **👤 참가자 A (찜 목록 조작 방식 불일치)**
  * **불편점**: 앱마다 찜(관심상품) 삭제 UI 방식이 달라서 헷갈림.
  * **세부 내용**: 어떤 앱은 체크박스로 바로 일괄 삭제되는데, 어떤 앱은 개별 상품에 들어가서 취소해야 하거나 삭제 버튼 위치를 어렵게 찾아야 함.

* **👤 참가자 B (뒤로가기 시 스크롤 위치 초기화)**
  * **불편점**: 상품을 보다가 `[뒤로가기]`를 누르면 **스크롤이 맨 위로 리셋**됨.
  * **세부 내용**: 목록 하단까지 내려가서 상품을 구경하다가 클릭 후 뒤로 나오면 기존 위치가 유지되지 않고 화면 맨 위로 올라가 버려 다시 아래로 스크롤해야 함.

* **👤 참가자 C (품절 상품 방치 및 위치 문제)**
  * **불편점**: 품절된 상품이 장바구니나 찜 목록 중간에 그대로 방치됨.
  * **개선 희망**: 쿠팡처럼 품절된 상품은 목록 맨 아래로 자동 이동시켜주거나 한꺼번에 정돈할 수 있는 기능이 필요함.

* **👥 공통 추가 의견 (가격 변동 알림)**
  * 장바구니나 찜 목록에 담아둔 상품의 가격이 인하되거나 할인이 시작되면 바로 구매할 수 있도록 **가격 변동 알림**을 원함.

## 3. 🧘 주제 3: 체형 교정 / 헬스케어 제품 구매 경험 및 개선 요청 (스밈 SEUMIM 핵심 연계)

### ❓ 진행자 질문
> **"체형 교정용품(교정 밴드, 깔창, 마사지기 등)을 구매해 본 적이 있으신가요? 구매 과정과 불편했던 점은 무엇이었나요?"**

### 💬 참가자별 발언 정리

* **👤 참가자 A (유튜브 리뷰 탐색형)**
  * **탐색 경로**: 유튜브에서 착용 브이로그/리뷰 검색 -> 브랜드 공식 몰에서 가격 확인 -> 쿠팡/대행사 가격 비교 후 구매.
  * **불편점**: 오프라인 시착이 불가능해 **리뷰만 보고 샀다가 사이즈/핏 착오로 실패**하는 경우가 많음.
  * **개선 아이디어**: AR/Virtual 시착 기능이나 **"30일/한달 무료 체험 시착 이벤트"**가 공식 몰에 있으면 좋을 것 같음.

* **👤 참가자 B (SNS/네이버 스마트스토어 진입형)**
  * **탐색 경로**: 인스타그램/유튜브 광고 -> 브랜드 네이버 스마트스토어 -> 장바구니 보관.
  * **불편점**: **"교정 제품은 항상 실패해서 방 구석에 안 쓰는 교정기/깔창이 쌓여 있다."** 금방 오작동하거나 통증이 발생함. 교정 제품 가격을 객관적으로 비교해 주는 플랫폼이 부족함.

* **👤 참가자 C (사이즈 규격 모호함 & 모델 착용 샷 불만)**
  * **탐색 경로**: 쿠팡 직접 검색 또는 유튜브 추천 링크 -> 리뷰 수 많은 상품 장바구니.
  * **불편점**:
    1. **사이즈 기준 모호**: 체형 교정기는 신체 밀착이 핵심인데 단순 S/M/L로만 표기되어 나한테 맞는지 알 수가 없음.
    2. **비현실적 모델 핏**: 모델들이 너무 마르고 비현실적이어서 일반인이 착용했을 때 느낌을 전혀 알 수 없음.
  * **개선 아이디어**:
    * **일반 의류/신발 규격 연계**: "일반 상의 95/100, 신발 235mm 기준"과 같이 직관적인 사이즈 기준표 제시.
    * **다양한 체형의 일반인 착용 사진**: 셔츠/오피스룩 안에 실제 입었을 때 티가 나는지 보여주는 실착 이미지 필요.

## 4. 🌸 주제 4: 향수 구매 패턴 및 상세페이지 문제점

### ❓ 진행자 질문
> **"향수 제품을 구매할 때는 어떤 과정을 거치고, 어떤 점이 불편했나요?"**

### 💬 참가자별 발언 정리

* **👤 참가자 A**: 올리브영 등 오프라인 매장에서 먼저 시향 -> 온라인/공식몰 검색 후 구매. 온라인 구매 시 향을 모르므로 **작은 샘플(1~2개)**을 사은품으로 같이 주면 좋겠음.
* **👤 참가자 B**: 유튜브 영상 브이로그 탐색 -> 브랜드 웹사이트 상세페이지 이동 -> 영상 설명과 상세페이지 일치 여부 확인 후 2~3개 비교 구매.
  * **불편점**: 상세페이지에서 **"부드러운 이불 느낌" 등 모호하고 추상적인 그림으로 때움**. 실제 무슨 향인지(포근함인지, 꽃향기인지) 구체적 설명이 부족함.
* **👤 참가자 C**: 은은한 향 위주로 리뷰 검색 후 구매. 향 표현 문구가 모호하여 실제 받았을 때 생각했던 향과 다른 경우가 많음. **사용자들의 실제 향 느낀 점(리뷰 모음)**이 상세페이지에 객관적으로 표시되면 좋겠음.

## 5. 🍵 주제 5: 차(Tea) 제품 구매 패턴 및 샘플/스타터키트 니즈

### ❓ 진행자 질문
> **"차(Tea)나 음료 제품을 구매할 때 경험과 개선 희망 사항은 무엇인가요?"**

### 💬 참가자별 발언 정리

* **👤 참가자 A & B**: 네이버/앱 랭킹 보고 구매하거나 유튜브 추천 티백 검색.
  * **불편점**: 차 제품도 향수처럼 "몽환적인 맛", "상쾌한 맛" 등 모호한 감성 문구로 설명되어 실패 확률이 높음.
* **👤 참가자 C (대량 구매 부담 및 스타터키트 제안)**:
  * **불편점**: 티백이나 차 제품은 한 번 살 때 **10개~20개씩 묶음으로 판매**하여, 입맛에 안 맞으면 뜯은 채로 처리(버리지도 못하고 주지도 못함)하기 곤란함.
  * **개선 아이디어**: 향수 샘플처럼 **여러 맛을 1개씩 맛볼 수 있는 "스타터 키트 / 샘플 팩"**을 판매하거나 사은품으로 제공해주면 구매 결정에 훨씬 도움이 될 것임.
