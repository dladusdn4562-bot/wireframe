## ⚡ 3. [기능 (Function & Interaction UI)] 분석 결과

### (1) 인터랙티브 데이터 시각화 기능
- **디스코드 봇 실시간 자세 점수 스트림 위젯 (Discord API 벤치마킹)**: 웹 화면에서 5인 파티원의 실시간 척추 밸런스 점수와 랭킹이 실시간으로 업데이트되는 HUD 위젯
- **목 각도별 에임 탄착군 시뮬레이터**: 목 각도 슬라이더 조작 시 마우스 에임의 흔들림 범위(DPI 분산도)를 보여주는 게이밍 인터랙티브 위젯

### (2) 전환 유도 (CTA) & 커머스 UI 기능
- **Discord OAuth 1-Click 무상 시착 신청 폼 (Discord 벤치마킹)**: 디스코드 계정 로그인 한 번으로 봇 초대 링크와 함께 30일 무상 시착 배송지 접수가 10초 만에 완료되는 UI
- **게이밍 상의 사이즈(95/100/105) 자동 매칭 모달**: 져지 핏에 딱 맞는 규격을 선택해 주는 팝업
