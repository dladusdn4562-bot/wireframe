## ⚡ 3. [기능 (Function & Interaction UI)] 분석 결과

### (1) 인터랙티브 데이터 시각화 & 비주얼 기능
- **0.1mm 실루엣 비포/애프터 비교 슬라이더**: 마우스 드래그로 작업복 착용 전/후 0.1mm 무봉제 은폐 상태를 실시간 비교.
- **실시간 척추 밸런스 HUD 대시보드 (Oura Ring 벤치마킹)**: 동물병원 외과 수술 및 처치 전문 수의사의 작업 중 척추 점수(94.8점), 경추 각도(14.2°), 좌우 체압(50:50)을 라이브 게이지로 시각화.
- **3D 단면도 인터랙션**: 대표 3종 카드의 자석 버클, 숨은 지퍼, 에어셀 패드 작동 원리 모식도 팝업.

### (2) 전환 유도 (CTA) & 커머스 UI 기능
- **15개 상품 4대 카테고리 실시간 탭 필터링**: 시그니처(4) / 케어(4) / 센서(4) / 직업ACC(3) 탭 클릭 시 0.2초 내 즉각 재배치.
- **상품 🔍 퀵뷰 (QuickView) 팝업 모달**: 페이지 이탈 없이 상품 3D 룩북, 스펙, 할인가, 30일 시착 신청 원스톱 처리.
- **전국 35개 센터 4단계 Wizard 예약 폼 (HigherDOSE 벤치마킹)**: 지점 선택 ➔ 일시 선택 ➔ 동물병원 외과 수술 및 처치 전문 수의사 작업 환경 입력 ➔ 예약 확정 알림톡 발송.
- **Floating Sticky CTA Bar (Alo Yoga 벤치마킹)**: 스크롤 시 화면 우측 하단 고정 (*"✨ 30일 에르고 무상 시착 (100% 무료 반품)"*).
