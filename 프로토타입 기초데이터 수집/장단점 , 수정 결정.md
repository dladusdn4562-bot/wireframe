## 1. 첫 완성본의 위치와 실제 구성

이 파일은 한 HTML에서 **메인 랜딩(`page-main`)·15종 상품 컬렉션(`page-shop`)·브랜드 이야기(`page-story`)**를 전환해 보는 프로토타입이다. 상단 GNB와 모바일 메뉴, 하단 고정 시착 CTA, 상품 퀵뷰·시착 모달, 브랜드 이야기의 B/A 슬라이더가 있다. 메인에서는 **매니페스토·4대 지표 → 브랜드 여정 3장 → 대표상품 3종의 지그재그 대형 카드 → 검증 수치·후기 → 15종 컬렉션 이동 배너 → 사이즈 파인더 → AI·센터 → FAQ** 순으로 진행한다. 15종 전체는 메인 안이 아니라 별도 상품 화면에서 **전체 + 부위별 3개 탭**으로 탐색한다. [병합본의 메인·상품 화면](../가상클라이언트%20설계%20결과/설계%20출력물/병합/와이어프레임_병합.html)

## 2. 첫 완성본의 장점

| 장점 | 첫 완성본에서 확인되는 근거 | 사용자에게 주는 가치 |
| --- | --- | --- |
| 브랜드 선언이 먼저 나온다 | 히어로의 ‘다정한 균형’, 압박 대신 편안함이라는 설명, 브랜드 여정 3장 | 단순 상품 나열보다 스밈의 존재 이유를 먼저 이해한다. |
| 대표작과 전체 라인업의 역할이 다르다 | 대표 3종은 각기 큰 독립 카드, 15종은 별도 컬렉션 그리드 | 핵심 제품을 깊게 본 다음 필요 부위를 탐색할 수 있다. |
| 비교를 시작하기 쉽다 | 15종 카드에 부위·상품명·스펙·가격·퀵뷰·시착 행동을 반복 배치 | 목록에서 상품을 1차 비교하기 쉽다. |
| 전환 경로가 끊기지 않는다 | GNB, 카드 CTA, 퀵뷰, 하단 고정 시착 바와 모달 | 읽다가 상품 또는 시착으로 이동할 수 있다. |
| 브랜드 이야기의 표현 폭이 넓다 | 어원·일상 문제·소재 확대·SVG 기술 도면·B/A 슬라이더·일상 장면 | 감성 사진과 기술 설명을 한 화면 체계에서 시험해 볼 수 있다. |
| 반응형 탐색을 고려했다 | 모바일 메뉴·카드 배치 변경·터치 가능한 B/A 슬라이더 코드 | 데스크톱 이외의 사용 흐름도 프로토타입에서 검토할 수 있다. |

## 3. 첫 완성본의 단점과 원인

| 단점 | 확인된 상태 | 수정 판단 |
| --- | --- | --- |
| 첫 화면과 메인이 과밀하다 | 히어로에 CTA 2개와 지표 4개, 이어서 긴 여정·대표작·큰 검증 구간·사이즈·AI·센터까지 배치 | 사용자가 원한 히어로의 흐름은 유지하되 초반 정보량과 중복 설명을 줄인다. |
| 검증 수치가 사실처럼 읽힌다 | `300+`, `87.4%`, 평점 4.9·5.0, 전문의 추천, 통증 감소, `99.8%` 등의 카피가 출처·시험 조건 없이 제시됨 | 가상 브랜드의 기획 수치로 명확히 표시하거나, 근거가 없으면 실제 성능·임상·후기 주장으로 쓰지 않는다. |
| 3D 설명과 동작이 다르다 | 대표 카드의 ‘3D 단면 분해도 보기’는 `openQuickView()`를 열고, 퀵뷰는 아이콘·텍스트 중심임 | 3D 뷰어라고 부르려면 회전·레이어·단면 조작을 구현한다. 현재 동작은 퀵뷰/기술 개요로 정확히 이름 붙인다. |
| 일부 기능은 시연용이다 | 센터 예약은 `alert()`, 시착 접수는 알림창으로 끝나며 AI 각도 HUD도 고정 예시 값임 | 실제 예약·접수·측정 기능으로 해석되지 않도록 프로토타입 상태를 표시한다. |
| 맞춤 추천 로직이 완결되지 않았다 | `renderProducts()`의 권장 배지는 `M`으로 고정되고, `calculateSize()`의 `L` 조건이 먼저 성립해 `XL` 분기에 도달할 수 없음 | 추천 값과 카드·시착 옵션을 한 상태로 연결하고 사이즈 조건을 수정한다. |
| 상품 분류가 현재 기획과 다르다 | 첫 완성본은 어깨·경추/척추·허리/골반·하체 3개 부위 탭이며, 메인에는 15종이 직접 펼쳐지지 않음 | 현재 규격의 **4대 카테고리·메인 하단 15종 쇼케이스**를 적용할 때 별도 재설계가 필요하다. |
| 비주얼 완성도에 편차가 있다 | 브랜드 이야기는 실사와 SVG가 있으나 대표 3종 및 15종 카드 이미지는 상당 부분 이모지·텍스트 플레이스홀더 | 제품별 실제 착용 컷·원단 매크로·단면 도해를 우선 채운다. |
| B/A 비교의 증명력은 제한된다 | 슬라이더는 서로 다른 장면의 두 이미지를 좌우로 겹쳐 보여준다 | 인터랙션 데모로는 유효하지만 실제 착용 효과 증거로 설명하지 않는다. |

장단점은 [첫 완성 HTML](../가상클라이언트%20설계%20결과/설계%20출력물/병합/와이어프레임_병합.html)의 마크업과 JavaScript를 기준으로 했다. 위 수치와 효능은 **화면 속 문구**를 인용한 것이며 검증된 제품 사실이라는 뜻이 아니다.

2. **상품 탐색을 현재 기획과 맞추기:** 첫 완성본의 부위별 3탭/별도 컬렉션 구조와 현재의 **4대 카테고리/메인 하단 15종 쇼케이스** 요구 중 적용할 규격을 명시하고 화면을 일치시킨다.
3. **데모와 완성 기능을 구분하기:** 3D·AI·센터 예약·시착 접수의 실제 구현 범위를 버튼 문구와 맞춘다.
4. **제품 비주얼을 보강하기:** 대표 3종부터 착용 컷·원단 매크로·단면 도해를 채우고 브랜드 이야기의 관련 없는 이미지를 교체한다.
5. **사이즈 상태를 한 번에 연결하기:** 추천 규칙을 고친 뒤 추천값이 상품 카드·퀵뷰·시착 옵션에 똑같이 나타나게 한다.

**기록상 주의:** 첫 완성본은 대표작을 지그재그 큰 카드로 놓는다. 후속 인수인계서는 3열 비교 카드로의 변경을 기록한다. 이는 서로 다른 시점의 화면 결정이다.
