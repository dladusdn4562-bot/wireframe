## 4. 글로벌 구조 참고와 내부 병합 흔적

[`사이트분석결과_가상클라이언트_90`](../../../가상%20클라이언트%20모음/사이트%20분석%20결과/사이트분석결과_가상클라이언트_90_스밈_웰니스융합마스터.md)는 Eight Sleep·Forme Science 등을 포함한 웰니스 롤모델을 GNB, 대표작, 기능·전환 흐름의 배경으로 기록한다. [`사이트분석결과_가상클라이언트_92`](../../../가상%20클라이언트%20모음/사이트%20분석%20결과/사이트분석결과_가상클라이언트_92_스밈_브랜드스토리_직장인척추혁신.md)는 브랜드 스토리의 스크롤 진행, 큰 소재 이미지, 3D 도면 카드, 전후 비교, 사용 장면을 분석한다. 병합 HTML 주석에는 `와이어프레임_90 원본`이 명시되고, 브랜드 이야기 요소에는 `st92` 식별자가 남아 있다. 이 관계는 **외부 사이트 직접 모방**보다 **프로젝트 내부 화면안을 결합한 과정**을 설명하는 증거에 가깝다.

- **메인 흐름:** 고정 GNB → 브랜드 매니페스토·4개 지표 → 여정 → 대표작 3종의 큰 카드 → 신뢰 지표 → 15종 컬렉션 진입 → 사이즈 안내·시착 CTA.
- **컬렉션 흐름:** 전체/어깨·경추/척추·허리/골반·하체 탭 → 15종 카드 → 퀵뷰 또는 시착 모달.
- **브랜드 이야기 흐름:** 대형 사진 히어로 → 이름의 유래 → 일상 문제 → 3대 철학 → 소재 확대 → 기술 도면 → 전후 비교·일상 사례 → 컬렉션.
- **실제 리소스:** `assets/img/`에 직장인·라이프스타일 JPEG가 저장되어 있고, HTML은 Google Fonts의 Gowun Batang·Pretendard 및 CDN의 MaruBuri를 호출한다. 이 이미지·폰트는 화면 자산이며, 위 레퍼런스 사이트에서 가져온 자산이라는 기록은 없다.

## 5. 해석 시 주의할 차이

1. **기획 규격과 현재 HTML은 다르다.** 최신 [`AGENTS.md`](../../../AGENTS.md)와 병합 스토리보드 목록은 메인 하단 15종 쇼케이스를 **4대 카테고리 탭**으로 제시한다. 실제 병합 HTML은 메인에서 컬렉션으로 이동하는 배너를 제공하고, 별도 `#page-shop`에서 **3개 부위별 라인 × 5종**으로 필터링한다. 이 문서는 현재 HTML의 구현을 기록한다.
2. **신뢰 수치는 검증 자료가 아니다.** HTML의 38g, 99.8%, 300+, 87.4%, 평점·후기·의료 효능 표현은 와이어프레임에 들어 있는 카피다. 위 레퍼런스 사이트가 스밈 상품의 성능이나 임상 결과를 입증하지 않는다.
3. **3D 뷰어라는 문구와 구현 수준을 구분해야 한다.** 대표작 카드는 `3D 단면 분해도 보기`라고 표기하지만 실제 클릭 동작은 `openQuickView()` 모달을 여는 코드다. 소재·기술 도면은 SVG와 카드 인터랙션으로 표현된다.
4. **210개 리서치 전체를 직접 출처로 간주하지 않는다.** 저장소에는 대규모 선별·분석 보고서가 있지만, 이 HTML의 각 섹션과 210개 사이트를 일대일로 연결한 기록은 없다.
