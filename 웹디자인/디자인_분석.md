## 1. 개요 및 디자인 분석 프레임워크

본 문서는 사용자가 선별한 기존 4대 레퍼런스의 **카테고리 페이지**와 **브랜드 소개 페이지**가 가진 고유한 **시각 디자인 언어(Visual Design Language)**를 추출하여, 우리 웹사이트의 상품 쇼케이스와 브랜드 서사에 최적화된 그래픽 스타일을 도출하는 것을 목적으로 합니다.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        [카테고리 & 브랜드 소개 페이지 2대 핵심 축]                              │
├──────────────────────────────────────────┬─────────────────────────────────────────────┤
│ 🛍️ 1. 카테고리 페이지 (쇼케이스 & 목록)  │ 📖 2. 브랜드 소개 페이지 (스토리 & 철학)    │
│ • 상품/객실/혜택이 한눈에 읽히는 카드 룩앤필│ • 감성을 자극하는 서사적 타이포그래피 & 여백│
│ • 1px 라인, 뱃지, 불릿, 탭 인디케이터   │ • 자연광 감성 컷, 계단식 인덴트, 명조 헤드  │
└──────────────────────────────────────────┴─────────────────────────────────────────────┘
```

- **대표 URL**: `https://sadamjae.com/html/sub2_room4.html` (Rooms - 재연/사유/담화), `sub3_special1.html` (Special)

```
┌────────────────────────────────────────────────────────────────────────┐

│                                                                        │
│  ┌───────────────────────┐  ┌────────────────────────────────────────┐ │
│  │                       │  │ ▪ 객실 구성: 개인정원 / 자쿠지 / 다실    │ │
│  │   [자연 채광 실사컷]   │  │ ▪ 객실 정보: 기준 2인 ~ 최대 6인        │ │
│  │   원목/노천탕/정원 질감│  │ ▪ 비치 품목: 관문요 다도, 발뮤다 티팟   │ │
│  │                       │  │   [ 1px 우드브라운 Outline 예약하기 ]    │ │
│  └───────────────────────┘  └────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────┘
```

* **시각적 톤앤매너**:
  - **배경 & 색감**: 웜 아이보리/소프트 린넨 (`#FBF9F5`, `#F5F2EB`) 베이스에 차분한 웜 우드 브라운 (`#8C6D53`) 라인.
  - **사진 스타일**: 인공 조명을 배제하고 창문으로 들어오는 자연광과 석재/원목/온천수의 촉감이 살아있는 4:3 감성 컷.
* **타이포그래피 디테일**:
  - **카테고리 타이틀**: 한자 인장 모티프 (`斎緣`, `思惟`)와 함께 32px 본명조(Noto Serif KR)로 품격을 부여하고, 서정적인 한글 부제 병기.
  - **스펙 & 안내문**: 15px 산세리프, 행간 1.8로 넉넉하게 띄워 텍스트가 시원하게 숨 쉬는 느낌.
* **컴포넌트 & 그래픽 요소**:
  - **1px 미세선 버튼**: `border: 1px solid #8C6D53`, 모서리 곡률 `2px`의 절제된 아웃라인 버튼.
  - **정보 리스트**: 복잡한 테이블 박스 대신, 텍스트 불릿(`▪`)과 1px 옅은 가로선만으로 여백감 있게 구획.
