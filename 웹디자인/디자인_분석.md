## 🛍️ 2. [카테고리 쇼케이스 디자인] 레퍼런스 심층 재분석

### 2.1 E1 오렌지카드 : 압도적 정보 전달력의 One-View 카드 구조
- **분석 관점**: 정보의 복잡성을 제거하고 한 장의 카드 안에서 스펙/혜택을 1초 만에 파악하게 하는 레이아웃
- **5대 원칙 적용 포인트**:
  - **③ 폰트/사이즈 강조**: 20px Bold 상품명 + 14px 모노스페이스 모델명 + 3줄 핵심 혜택 불릿 포인트의 확실한 위계.
  - **⑤ 시각적 즐거움**: 카드 마우스 호버 시 4px 부드러운 상승 엘리베이션(`translateY(-4px)`), 1px 테라코타 글로우 테두리 전환.
  - **카드 내부 구조**:
    ```
    ┌──────────────────────────────────────────────────────────┐
    │ [카테고리 뱃지: 어깨·경추]        [체형 맞춤 권장: M 사이즈]│
    │                                                          │
    │             [ 0.1mm 심리스 넥&숄더 밴드 ]                  │
    │                 "깃털처럼 가볍게 말린 어깨를 열다"           │
    │                                                          │
    │  ┌────────────────────────────────────────────────────┐  │
    │  │  [자연광 매크로 질감 이미지 / 3D 단면 일러스트]      │  │
    │  └────────────────────────────────────────────────────┘  │
    │                                                          │
    │  ▪ 0.1mm 초슬림 무봉제 융착: 얇은 셔츠 속 99.8% 은폐      │
    │  ▪ 38g 초경량 에어로 메쉬: 목/승모근 압박 제로 실현       │
    │  ▪ 네오디뮴 전면 원터치 버클: 1초 만에 간편 탈착           │
    │                                                          │
    │  [ 🔍 3D 단면 퀵뷰 ]          [ 30일 무료 시착 신청 ➔ ]    │
    └──────────────────────────────────────────────────────────┘
    ```

### 2.2 모두의매트 : 직관적 카테고리 필터링 & 캡슐형 Pill UI
- **분석 관점**: 사용자가 탐색 피로도 없이 즉시 원하는 카테고리를 전환할 수 있는 직관적인 내비게이션
- **5대 원칙 적용 포인트**:
  - **① 따뜻하고 편안함**: 각진 사각형 탭 대신 `border-radius: 9999px`의 조약돌 같은 캡슐형 Pill 탭 버튼 적용.
  - **④ 브랜드 컨셉 반영**: 신체 부위별(어깨·경추 5종, 척추·허리 5종, 골반·하체 5종)로 스밈의 3대 다정한 균형 철학에 맞춘 직관적 카테고리 분류.
  - **⑤ 시각적 즐거움**: 탭 클릭 시 카드가 부드럽게 재배치되는 페이드인 애니메이션.

### 2.3 사담재 & 이솝 : 웜 어스톤 1px 헤어라인 & 자연광 매크로 컷
- **분석 관점**: 상업적인 광고판 느낌을 덜어내고, 고급 갤러리/에디토리얼 매거진의 품격을 부여하는 시각 요소
- **5대 원칙 적용 포인트**:
  - **① 따뜻함 & ② 탈의학적**: 차가운 순백색 카드 대신 웜 아이보리 카드 바탕(`--bg-card: #FFFFFF`, 베이스 배경 `#FAF7F2`)과 1px 웜 우드 헤어라인(`rgba(35, 33, 30, 0.12)`).
  - **④ 브랜드 컨셉**: 인체공학적 디테일(원단 질감, 봉제선 없음, 자석 래치)을 자연광이 들어오는 일상 배경 매크로 컷으로 표현하여 의학 보조기가 아닌 라이프스타일 웰니스 아이템으로 포지셔닝.

### 2.4 가까이한의원 : 신뢰감을 주는 스마트 사이즈 파인더 연동
- **분석 관점**: 환자 맞춤 진단 경험을 e-커머스 카테고리 쇼케이스에 녹여내는 방식
- **5대 원칙 적용 포인트**:
  - **③ 강조**: 사용자의 키/몸무게를 입력받아 각 카드 상단에 `[● 내 체형 권장: M 사이즈]` 뱃지를 선명하게 강조.
  - **② 탈의학적**: 복잡한 체질 분류 대신 "일상에서 편안한 체형 맞춤" 언어로 순화하여 제공.

## 📖 3. [브랜드 이야기 디자인] 레퍼런스 심층 재분석

### 3.1 모두의매트 : 대형 스트로크 타이포 & 5단계 집요한 공정 서사
- **분석 관점**: 왜 이 제품을 만들었는지에 대한 진정성을 시각적 충격과 압도적 신뢰로 전환하는 레이아웃
- **5대 원칙 적용 포인트**:
  - **③ 확실한 폰트·사이즈 강조**: `clamp(80px, 12vw, 150px)` 크기의 대형 스트로크 타이포(`0.1mm`, `99.8%`)를 배경/헤드에 배치하여 브랜드의 핵심 기술력을 한눈에 각인.
  - **④ 브랜드 컨셉 전달**: 5단계 집요한 연구 공정(`01. 문제 발굴` ➔ `02. 38g 경량화` ➔ `03. 무봉제 융착` ➔ `04. 300인 실착` ➔ `05. 30일 안심보증`)을 계단식 인덴트 레이아웃으로 전개.
  - **⑤ 시각적 즐거움**: 마우스 오버 시 각 공정 행(`process-step-row`)이 은은한 웜 오렌지빛으로 활성화되는 반응형 피드백.

### 3.2 사담재 · 킨포크 · 시리얼 : 한옥의 온기와 서정적 본명조 에디토리얼
- **분석 관점**: 브랜드의 철학과 감성을 한 편의 수필이나 하이엔드 라이프스타일 매거진처럼 읽히게 하는 서사 구조
- **5대 원칙 적용 포인트**:
  - **① 따뜻하고 편안함**: 샌드 베이지/웜 크림 배경 위에 서정적인 한글 본명조(`Noto Serif KR`, 마루부리) 타이포그래피 전면 적용.
  - **② 탈의학적 룩**: 딱딱한 치료/교정 문구 대신 *"우리는 몸을 억지로 조이는 대신, 일상에 자연스럽게 스며들기로 했습니다"*와 같은 다정한 문학적 카피라이팅.
  - **⑤ 눈의 피로 완화**: 860px의 최적 칼럼 너비와 1.85의 넉넉한 줄간격(Line-height)으로 장시간 스크롤에도 눈이 편안한 에디토리얼 리딩 환경 조성.

### 3.3 가까이한의원 : 스밈의 어원 & 브랜드 탄생 비하인드 대형 섹션
- **분석 관점**: 소비자가 겪고 있던 기존 교정기의 고통에 깊이 공감하고, 브랜드 이름의 탄생 배경을 진솔하게 풀어내는 방식
- **5대 원칙 적용 포인트**:
  - **④ 브랜드 컨셉**: '스밈(SEUMIM)'의 순우리말 어원 *"빛이나 물이 천천히 배어들듯, 마음에 자연스럽게 녹아들다"*를 엠블럼 박스로 시각화.
  - **③ 강조**: `스·밈 [SEUMIM]` 44px 대형 타이포 아트 + 테라코타 포인트 컬러 강조.
  - **② 탈의학적**: 기존 쇠붙이 교정기의 흉터/압박감 vs 스밈의 0.1mm 무봉제 스킨터치의 따뜻한 일상 대비.

### 3.4 프라마 · 테클라 · 이솝 : 3D 엔지니어링 도면 & 패브릭 물성 분해도
- **분석 관점**: 만져질 듯한 패브릭 텍스처와 감각적인 3D CAD 단면도를 결합한 하이엔드 테크 비주얼
- **5대 원칙 적용 포인트**:
  - **④ 브랜드 컨셉 & ⑤ 시각적 즐거움**: 마우스 움직임에 반응하는 **3D 카드 인터랙티브 틸트 (Perspective Tilt)** 효과 구현.
  - **③ 모노스페이스 수치 강조**: 0.1mm 나노 코어, 네오디뮴 자석 래치, 3중 에어로 메쉬 등의 정밀 수치를 `IBM Plex Mono` 폰트로 또렷하게 대비.

## 🛠️ 5. `기본 와이어프레임.html` 전면 적용 설계 내역

1. **CSS `:root` 디자인 토큰 The Warm Earth Harmony v2.0 완성**:
   - 베이스 배경: `#FAF7F2` (따뜻한 밀크티 아이보리)
   - 서피스 배경: `#F4EFE6` (차분한 샌드 베이지)
   - 카드 배경: `#FFFFFF` (부드러운 소프트 웜 섀도우)
   - 포인트 컬러: `#D9531E` (웜 테라코타), `#234253` (딥 웰니스 포레스트), `#2AB673` (허벌 세이지)
2. **타이포그래피 계층(Typographic Scale) 극대화**:
   - `Noto Serif KR` (300, 500, 700, 900) 대제목 및 감성 헤드라인
   - `IBM Plex Mono` (500, 700) 수치/지표/태그
   - `Pretendard` (400, 500, 600, 700) 본문 및 UI 컴포넌트
3. **카테고리 뷰 (`#page-shop` & 메인 쇼케이스)**:
   - 15종 전 상품 One-View 카드에 3줄 감성 효능, 권장 사이즈 뱃지, 부드러운 호버 애니메이션 완비.
4. **브랜드 이야기 뷰 (`#page-story`)**:
   - 01. 매니페스토 ➔ 02. 스밈의 어원과 탄생기 ➔ 03. 일상 3대 문제 공감 ➔ 04. 3대 다정한 균형 ➔ 05. 0.1mm 심리스 기술 ➔ 06. 3D 엔지니어링 CAD 분해도(3D 틸트 인터랙션) ➔ 07. 전후 B/A 슬라이더 ➔ 08. 15종 컬렉션 8단계 풀 서사 완성.
