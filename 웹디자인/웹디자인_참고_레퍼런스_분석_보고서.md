## 1. 개요 및 11대 분석 프레임워크

본 문서는 `레퍼런스 분석 기준`에 정의된 **11대 핵심 디자인 기준**에 따라, 사용자의 심미적 취향인 **"따뜻한 온기, 정갈한 명조 타이포그래피, 1px 극세선, 자연광 질감"**을 구현하는 국내외 9개 대표 웹사이트의 순수 시각 디자인 요소를 정밀 분석합니다.

### 📌 11대 레퍼런스 분석 기준 체계
1. **브랜드 분위기와 핵심 디자인 키워드** (Brand Mood & Core Keywords)
2. **로고 사용 규칙** (Logo Rules & Visual Hierarchy)
3. **주색·보조색·강조색과 색상 코드** (Color Palette & Hex Codes)
4. **제목·본문·버튼의 글꼴과 크기 체계** (Typography Hierarchy & Scale)
5. **여백, 화면 폭과 그리드 규칙** (Spacing, Viewport Width & Grid System)
6. **버튼·상품 카드·필터·입력창·팝업창의 공통 형태** (UI Components: Shapes, Radius, Shadow)
7. **이미지 비율, 촬영 분위기와 사용 장면** (Imagery Style, Aspect Ratios & Scenes)
8. **아이콘과 선의 굵기** (Iconography & Stroke Weight)
9. **PC·태블릿·모바일 화면 변화** (Responsive Breakpoints & Layout Adaptations)
10. **기본·선택·마우스를 올린 상태·오류·완료 상태** (Interactive States & Micro-interactions)
11. **실제 화면 예시와 사용하면 안 되는 사례** (Best Practices & Anti-patterns / Do's & Don'ts)

## 2. 레퍼런스 1 : 사담재 (Sadamjae)
- **URL**: `https://sadamjae.com/html/sub2_room4.html`
- **시각적 아이덴티티**: 한국적 젠(Zen) 미학, 정제된 고요함, 따뜻한 온기, 사색과 대화, 특별하지만 친근한 분위기.

### 1) 브랜드 분위기와 핵심 디자인 키워드
- `#WarmMinimalism`, `#OrientalZen`, `#TactileCalm`, `#ThoughtfulRest`, `#NaturalTexture`
- 차가운 메디컬 느낌을 배제하고, 자연광과 원목 질감이 감도는 편안하고 친근한 웰니스 분위기.

### 2) 로고 사용 규칙
- **형태 & 배치**: 영문 세리프 로고타입 `Sadamjae` 및 한자 인장 모티프를 상단에 미니멀 배치. 상하 24px, 좌우 32px 클리어스페이스 확보.

### 3) 주색·보조색·강조색과 색상 코드
- **주색 (배경/본문)**: 웜 크림/아이보리 (`#FBF9F5`, `#F5F2EB`) / 딥 차콜 (`#2B2A28`, `#33312E`)
- **보조색 (면/보더)**: 린넨 샌드 (`#EAE5DB`) / 스톤 그레이 (`#D8D2C4`)
- **강조색 (포인트)**: 웜 우드 브라운 (`#8C6D53`) / 미티드 클레이 (`#A47E65`)

### 4) 제목·본문·버튼의 글꼴과 크기 체계
- **서체군**: 한글 본명조(Noto Serif KR) / KoPub 바탕체 (헤드라인) + 본고딕/Pretendard (본문).
- **크기 체계**:
  - 대제목 (H1/H2): 36px~44px, Weight 400~600, 행간 1.4~1.5, 한자 명칭(斎緣, 思惟) 병기.
  - 중제목/서브카피: 20px~24px, Weight 400, 행간 1.6.
  - 본문 (Body): 15px~16px, Weight 300~400, 행간 1.8~1.9.

### 5) 여백, 화면 폭과 그리드 규칙
- **최대 폭**: 1280px ~ 1400px. 상하 패딩 120px~180px의 대담한 네거티브 스페이스(여백).
- **그리드**: 2단 비대칭 분할 (좌측 대형 무드 컷 55% : 우측 텍스트 정보 45%).

### 6) 버튼·상품 카드·필터·입력창·팝업창의 공통 형태
- **버튼**: 모서리 곡률 `2px~4px` 또는 타원(`9999px`)의 미니멀 1px 라인 아웃라인 (`border: 1px solid #8C6D53`).
- **카드**: 테두리선/그림자 없이 넉넉한 여백과 배경색 차이만으로 구역을 나누는 플랫 카드.

### 7) 이미지 비율, 촬영 분위기와 사용 장면
- **비율**: 4:3, 16:10, 3:2 와이드 비율.
- **촬영 톤앤매너**: 인위적인 조명을 배제하고 자연 채광(햇살, 그림자)을 살린 감성 컷. 원목 다도구, 노천탕, 린넨 침구의 생생한 질감.

### 8) 아이콘과 선의 굵기
- **아이콘 & 선**: 1px~1.2px의 극세선(Hairline), 불투명도 20~30%의 섬세한 구분선.

### 9) PC·태블릿·모바일 화면 변화
- **PC**: 좌측 와이드 비주얼 + 우측 서정적 정보 병렬 배치.
- **모바일**: 1열 수직 스택으로 재배치, 전체화면 햄버거 오버레이 메뉴 제공.

### 10) 인터랙티브 상태 (Interactive States)
- **호버 (Hover)**: 이미지 1.03배 미세 줌인(`scale 1.03`, transition 0.4s ease-out), 링크 텍스트 투명도 70% 페이드.

### 11) 실제 화면 예시와 사용하면 안 되는 사례
- ⭕ **Do**: 서정적인 헤드카피 + 자연광 고화질 실사컷의 유기적 조화.
- ❌ **Don't**: 형광 원색 배너, 번쩍이는 팝업, 빽빽한 테이블 나열 엄격 배제.

## 3. 레퍼런스 2 : 가까이한의원 (Kakkai)
- **URL**: `https://kakkai.co.kr/`
- **시각적 아이덴티티**: 임상적 전문성(Clinical Trust), 환자 중심의 따뜻한 소통, 데이터 기반의 객관적 증명.

### 1) 브랜드 분위기와 핵심 디자인 키워드
- `#ClinicalCredibility`, `#DataDrivenProof`, `#InstantClarity`, `#PatientCentric`

### 2) 로고 사용 규칙
- 영문 `Kakkai` + 국문 `가까이한의원` 조합 워드마크 좌측 상단 배치. 스크롤 시 상단 고정 바(Sticky Header) 유지.

### 3) 주색·보조색·강조색과 색상 코드
- **주색**: 딥 메디컬 네이비 / 딥 틸 (`#1B2E3C`, `#234253`)
- **보조색**: 클린 화이트 / 라이트 그레이 (`#FFFFFF`, `#F8F9FA`, `#F1F3F5`)
- **강조색**: 세이지 그린 (`#2AB673`, `#3A9B7A`) / 신뢰 앰버 오렌지 (`#D97706`)

### 4) 제목·본문·버튼의 글꼴과 크기 체계
- **서체군**: Pretendard / Noto Sans KR (산세리프 단일 패밀리).
- **크기 체계**:
  - 메인 슬로건 (H1): 38px~48px, Bold.
  - 섹션 타이틀 (H2): 28px~32px, Bold + 영문 서브 레이블 (`Differentiation 01`).
  - 신뢰 수치 (Number): 48px~64px Extra Bold (`100%`, `93%`, `98%`).
  - 본문 (Body): 15px~17px, Regular, Line-height 1.6~1.7.

### 5) 여백, 화면 폭과 그리드 규칙
- **화면 폭**: 1200px. 섹션 간 80px~100px. 4열 카드 그리드.

### 6) 버튼·상품 카드·필터·입력창·팝업창의 공통 형태
- **4대 차별점 카드**: 라운드 `8px~12px`, 1px 보더(`border: 1px solid #E9ECEF`) + 호버 시 섀도우 상승.
- **플로팅 바**: 하단 고정 액션 바 (`[ 카톡 ] [ 네이버 예약 ] [ 전화 ]`).

### 7) 이미지 비율, 촬영 분위기와 사용 장면
- **비율**: 1:1 정방형, 4:3 썸네일. 밝고 청결한 원내 인테리어, 정밀 진료 장면.

### 8) 아이콘과 선의 굵기
- 1.5px~2px 두께의 명확한 라인 아이콘 (차트, 돋보기, 한약, 척추 모티프).

### 9) PC·태블릿·모바일 화면 변화
- PC 4열 카드 ➔ 태블릿 2열 ➔ 모바일 1열 스택 / 2x2 그리드.

### 10) 인터랙티브 상태
- **호버 (Hover)**: 케이스 카드 호버 시 치료 전 ➔ 후 MRI 이미지 및 호전 데이터 즉시 전환(Toggle Reveal).

### 11) 실제 화면 예시와 사용하면 안 되는 사례
- ⭕ **Do**: 초반 4대 차별점 및 전후 증명 데이터 즉각 노출.
- ❌ **Don't**: 메인페이지가 지나치게 길어지는 스크롤 피로감 지양.

### 2) 로고 사용 규칙
- GNB 좌측 상단 배치 + 서브페이지 상단 Breadcrumb(`제휴혜택 > 제휴카드`) 노출.

### 3) 주색·보조색·강조색과 색상 코드
- **주색**: 활력 오렌지 (`#E66300`, `#FF7700`)
- **보조색**: 옐로우/그린 (`#FEBF23`, `#8DC63F`) / 배경 화이트/라이트 그레이 (`#FFFFFF`, `#F8F8F8`)
- **텍스트**: 다크 차콜 (`#1D2023`, `#4E575E`) / 라인 (`#E8ECEF`)

### 4) 제목·본문·버튼의 글꼴과 크기 체계
- **서체군**: Pretendard / Uni 산세리프.
- **크기 체계**:
  - 카드명 (H3): 18px~22px, Bold.
  - 핵심 혜택 불릿: 14px~16px, 불릿(•)과 함께 3줄 압축 요약.
  - 부가 조건: 12px~13px Muted Gray.

### 5) 여백, 화면 폭과 그리드 규칙
- 1180px ~ 1200px 컨테이너, 3열 카드 그리드, 카드 내부 패딩 24px~32px.

### 6) 버튼·상품 카드·필터·입력창·팝업창의 공통 형태
- **원뷰(One-View) 카드**: 카드 1장 안에 [썸네일 + 핵심 3대 혜택 + 스펙 + CTA] 완결.
- **모서리 라운드**: `12px~16px`, `border: 1px solid #E8ECEF`.

### 7) 이미지 비율, 촬영 분위기와 사용 장면
- 가로/세로 카드 플레이트 렌더링 (1.58:1 비율), 투명 배경 깔끔한 제품 누끼.

### 8) 아이콘과 선의 굵기
- 1.5px 두께의 기능형 아이콘 및 컬러 뱃지.

### 9) PC·태블릿·모바일 화면 변화
- PC 3열 그리드 ➔ 모바일 1열 전체 폭 카드로 전환 (3줄 불릿 유지).

### 10) 인터랙티브 상태
- 카드 호버 시 섀도우 상승(`box-shadow: 0 10px 25px rgba(0,0,0,0.08)`), 버튼 색상 반전.

### 11) 실제 화면 예시와 사용하면 안 되는 사례
- ⭕ **Do**: 카드 겉면에서 3대 스펙을 비교할 수 있는 친절한 One-View 카드 설계.
- ❌ **Don't**: 스펙을 보려면 무조건 상세를 눌러야 하는 불친절한 갤러리 뷰 배제.
