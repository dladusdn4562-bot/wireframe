# Website Reference Analyzer Skill

이 스킬은 웹사이트 레퍼런스 리서치 자료를 수집, 정돈, 정량 통계화하여 신규 웹사이트 기획 및 제작에 필요한 실전 인사이트 보고서를 자동 작성하는 표준 프로세스입니다.

---

## 1. 스킬 입력 및 인식 규칙 (Skill Input Rules)

1. **기본 자료 우선 탐색 및 중복 차단**: 
   - `리서치/` 폴더 내에 `스밈_웹사이트_기획_레퍼런스_통합234선.txt` 파일이 존재할 경우, 중복 데이터 수집을 방지하기 위해 **해당 통합 파일 1개를 최우선 기본 자료로 사용**한다.
   - 통합 파일이 없을 경우 `[리서치 결과]`, `레퍼런스`, `리서치` 키워드가 들어간 TXT/MD 파일(예: `기존200선.txt`, `신규42선.txt`)을 수집하되, 사이트명/URL 기준 중복 제거(Deduplication)를 1단계 전처리로 필수 실행한다.
2. **추가 자료 인식 명령**:
   - 사용자가 `"리서치 자료 추가 입력"`이라고 명령한 이후 제공하는 파일, URL, 텍스트는 모두 추가 리서치 자료로 인식한다.
3. **원문 보존 및 덮어쓰기 금지**:
   - 기본 자료 및 추가 자료의 원본 텍스트는 절대로 덮어쓰거나 수정하지 않는다.
4. **출처 구분 기재**:
   - 추출 및 분석된 모든 정보에는 해당 데이터가 '기본 자료(파일명)'에서 왔는지 '추가 자료(파일명/URL)'에서 왔는지 출처를 구별하여 명시한다.
5. **중복 홈페이지 통합 및 출처 보존**:
   - 동일한 웹사이트가 중복 수집된 경우 1개 대상으로 통합하되, 발견된 모든 출처 파일명 기록을 빠짐없이 병기한다.
6. **통합 종합 분석**:
   - 모든 분석 및 보고서 작성 시 기본 자료와 추가 자료의 데이터를 함께 결합하여 분석한다.

---

## 2. AI 분석 작성 7대 원칙

1. **사실(Fact)과 해석(Interpretation) 구분**: 원문에 기재된 객관적 사실과 분석자의 추론/해석을 명확히 구분하여 작성한다.
2. **출처 명시 의무**: 모든 핵심 분석 내용 및 결론에는 근거가 된 출처(파일명/URL)를 반드시 표시한다.
3. **지어내기 절대 금지 (할루시네이션 방지)**: 텍스트 원문에 확인되지 않는 세부 이동 동선이나 기능을 임의로 지어내지 않는다.
4. **근거 부족 표시**: 확인이 어려운 내용은 사실처럼 단정하지 않고 "추정" 또는 "추가 확인 필요"로 표기한다.
5. **교차 대조 분석**: 단순 나열 요약에 그치지 않고 여러 홈페이지 간의 공통점, 차이점, 대조되는 패턴을 발굴한다.
6. **실전 실행 가능성 제공**: 신규 웹사이트 기획/제작에 즉시 적용 가능한 구체적 아이디어와 벤치마킹 타겟을 제안한다.
7. **비율 및 수치 표기**: 전체 수집 대상 대비 해당 패턴이 발견된 수량과 비율(%)을 명확히 표기한다.

---

## 3. 웹사이트 리서치 분석 8단계 프로세스

AI는 요청을 받으면 다음 8단계 순서에 따라 작업을 처리합니다:

1. **[1단계] 중복 통합 및 개별 분석**: 
   - 통합 파일 최우선 적용 및 중복 제거 후 각 홈페이지의 기본 정보, 디자인, 레이아웃, 흐름, 문구, 기능, 장단점을 추출한다.
2. **[2단계] 유사 요소 클러스터링**: 
   - 수집된 모든 홈페이지에서 유사하거나 반복되는 표현, 비주얼 스타일, 기능 요소를 그룹화한다.
3. **[3단계] 등장 횟수 및 비율 산출**: 
   - 각 클러스터 그룹별 발견 사이트 수와 비율(%)을 산출한다. (예: `상단 문의 버튼: 80개 (40.0%)`)
4. **[4단계] 3등급 패턴 분류**: 
   - **공통 패턴**: 전체의 30% 이상에서 발견된 표준 방식
   - **반복 패턴**: 10% 이상 ~ 30% 미만에서 발견된 트렌드 방식
   - **특이 사례**: 10% 미만이지만 아이디어 가치가 높아 벤치마킹할 독창적 사례
5. **[5단계] 공통점과 차이점 찾기**: 
   - 대세 방식, 업종별 차이점, 상충되는 방식, 특정 사이트 독창적 방식을 비교한다.
6. **[6단계] 패턴별 심층 평가 작성**: 
   - 각 패턴의 패턴명, 수량/비율, 대표 사이트, 장점, 단점, 어울리는 상황, 주의할 점을 정밀 평가한다.
7. **[7단계] 최종 인사이트 도출**: 
   - **[필수] 공통 방식**, **[선택] 상황별 선택 방식**, **[차별화] 독특한 차별화 방식** 3가지 전략으로 분류하고 출처를 연결한다.
8. **[8단계] 추가 조사 항목 명시**: 
   - 수집 자료만으로 판단이 불확실한 항목은 '추가 조사 필요 / 확인할 내용 / 부족한 근거'로 작성한다.

## 4. 결과물 파일 생성, 저장 경로 및 분할 규격

1. **저장 폴더 지정**: 모든 결과물 `.txt` 파일은 반드시 **`output/` 폴더(`C:\yyw\Antigravity\output\`)** 내에 생성 및 저장한다.
2. **포맷 & 인코딩**: 모든 결과물은 **UTF-8 인코딩의 `.txt` 파일**로 생성한다.
3. **수량 단위**: 홈페이지 1개 분석을 결과 1개 항목으로 계산한다.
4. **용량 제한 & 파일 분할**:
   - TXT 파일 1개당 최대 100개 항목을 수록한다.
   - 100개 초과 시 `01_홈페이지별_분석_001-100.txt`, `01_홈페이지별_분석_101-200.txt`, `01_홈페이지별_분석_201-234.txt` 형태로 연번 분할한다.
5. **원자성 보장**: 한 홈페이지의 분석 내역이 중간에 두 파일로 분할되지 않도록 1개 파일에 완결되게 작성한다.
6. **결과 파일 3종 구조**:
   - `output/01_홈페이지별_분석_001-100.txt`: 1단계 개별 분석 정리표
   - `output/02_전체_비교_분석_001-100.txt`: 2~6단계 클러스터링, 수치 통계, 패턴 대조 및 심층 평가
   - `output/03_최종_인사이트_001-100.txt`: 7~8단계 3대 전략 인사이트 및 추가 조사 필요 항목
