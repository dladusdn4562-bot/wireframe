# 스킬 제목: SEUMIM 웹사이트 레퍼런스 정량/정성 심층 분석

이 Skill은 승인된 원본 리서치/분류 데이터를 논리적으로 해석하고 정량 수치 통계와 5대 핵심 영역별 패턴으로 구조화한다. 새로운 해결책(디자인/코드)을 직접 생성하거나 제안서를 만들지 않으며, 결과를 스스로 승인하지 않는다.

---

## 1. 승인 게이트 및 입력 확인

1. 프로젝트 내 [`리서치 MD.txt`](file:///C:/yyw/Antigravity/%EB%A6%AC%EC%84%9C%EC%B9%98%20MD.txt), `output/워크플로우_진행상황.md` 및 선행 결과 파일을 읽는다.
2. 선행 작업(데이터 수집 및 분류)의 상태가 `approved` 상태인지 확인한다.
3. 분석할 원본 데이터 파일(예: `output/02_분류결과/분류결과_데이터.md` 또는 `output/1차_수집결과_batch1.txt`)이 실제로 존재하는지 확인한다.
4. 승인 상태 또는 파일이 없으면 무엇이 필요한지 알리고 작업을 중단한다.
5. 사용자 요청: `$ARGUMENTS`

---

## 2. 분석 절차 및 기준 (핵심 로직)

1. **5대 핵심 분석 영역 추출:**
   - **디자인 스타일:** 비주얼 무드, 색상 팔레트, 폰트 및 그래픽 무드
   - **화면 구성과 레이아웃:** 메인 히어로 섹션, 헤더/메뉴 배치, 주요 섹션 배치 순서
   - **메뉴와 사용자 흐름 (User Flow):** GNB/LNB 내비게이션, CTA 버튼, 사용자 혼동 가능 지점
   - **문구와 콘텐츠:** 메인 카피라이팅, 신뢰 요소(후기/수치), 행동 유도 문구
   - **주요 기능 & 인터랙션:** GSAP 애니메이션, 3D 오브젝트, 스텝형 퀴즈, Bottom sheet 등
2. **유사 요소 클러스터링 & 정량 수치 산출:**
   - 수집된 항목 중 반복 발생하는 디자인/기능 요소를 그룹화(클러스터링)하고, 전체 대비 등장 횟수 및 비율(%)을 명확히 산출한다. (예: `상단 결제 Bottom sheet: 16개 (80.0%)`)
3. **3등급 패턴 분류:**
   - **공통 패턴:** 전체의 30% 이상에서 발견된 표준 방식
   - **반복 패턴:** 10% 이상 ~ 30% 미만에서 발견된 트렌드 방식
   - **특이 사례:** 10% 미만이지만 아이디어 가치가 높아 벤치마킹할 독창적 사례
4. **객관성 유지 & 인과관계 파악:**
   - 단일 사이트의 특이한 요소(Edge case)를 전체 시스템의 필수가치로 과장하지 않는다.
   - 각 패턴의 장점, 단점, 어울리는 상황, 주의할 점을 엄격히 분석한다.
5. **데이터 한계 및 추가 조사 항목 명시:**
   - 수집 데이터만으로 판단이 불확실한 항목(예: 모바일 실제 반응 속도, A/B 테스트 전환율 등)은 임의로 지어내지 않고 '추가 조사 필요 / 확인할 내용'으로 명시한다.

## 3. 작성 및 포맷팅

1. 분석 제목은 상태나 핵심 인사이트가 드러나는 결론형 문장으로 작성한다.
2. 발견된 모든 분석 결과(인사이트)에 원본 데이터의 출처(브랜드명, URL)를 연결하여 근거를 추적할 수 있게 한다.
3. 추정이나 가설은 확정된 사실처럼 적지 않고 조건부 해석임을 명시한다.

## 4. 저장과 상태 관리

1. 기존 분석 결과 파일이 있으면 `archive/` 폴더에 타임스탬프 이름(예: `archive/deep_analysis_YYYYMMDD_HHMMSS.md`)으로 보존한다.
2. 새 분석 결과를 지정된 경로(`output/03_심층분석/심층분석_보고서.md`)에 저장한다.
3. 상태표(`output/워크플로우_진행상황.md`)에서 현재 분석 단계를 `draft`로 변경한다.
4. 기존 분석이 변경되었으면, 이후 진행된 제안서나 디자인/개발 설계 단계를 `stale`로 변경하되 파일은 삭제하지 않는다.
