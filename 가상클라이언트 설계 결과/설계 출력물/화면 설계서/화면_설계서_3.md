# SEUMIM(스밈) 테크 개발자 웹 플랫폼 화면 설계서 (가상클라이언트 3: 강민우)

---

## 1. 프로젝트 및 설계 범위 (Project Overview & Scope)

- **프로젝트명**: 스밈(SEUMIM) 테크 개발자 실시간 다크모드 대시보드 & 스마트 척추 정렬 조끼 웹 플랫폼 화면 설계서
- **기획 대상 / 가상클라이언트**: 강민우 (31세, 풀스택 IT 엔지니어) & 테크 개발 직군 타깃
- **비즈니스 아키텍처**: 전도성 센서 스마트 조끼 HW 판매 + AI 미니멀 케어 SW 3개월 무료 라이선스 구독 + 개발자 전용 대시보드 연동
- **핵심 설계 목표**:
  1. IT 엔지니어 91.2%가 겪는 코딩 중 거북목/디스크 방지 및 오알림 없는 시차 필터링 검증
  2. 눈의 피로를 최소화하는 고밀도 풀 다크모드(#0B0F17) 및 터미널 콘솔 UI 구축
  3. 작업 흐름을 끊지 않는 스마트워치 퀵-글랜스 3초 링 UI 및 Web Bluetooth 실시간 스트리밍
  4. GitHub 1-Click 3개월 무료 라이선스 키 발급 및 의류 상의(95~110) 기준 30일 시착 신청 연동
- **설계 범위**: 사이트맵(`P-0.0` ~ `P-9.2`) 및 서비스 흐름도(`ST-01` ~ `ST-14`)에 정의된 총 14개 화면(페이지 9종 + 모달 3종 + 예외 2종)의 상세 UI/UX 및 인터랙션

## 2. 화면 ID 규칙 및 전체 화면 목록 (Screen Inventory)

## 3. 공통 UI 컴포넌트 및 글로벌 레이아웃 규격

### (1) 글로벌 상단 헤더 (GNB: Global Navigation Bar)
- **높이**: 데스크톱 72px / 모바일 60px (다크 #111827 상단 고정, 하단 1px #1E293B 라인)
- **구성 요소**:
  - **좌측**: 스밈 테크 로고 (`<SEUMIM_DEV />`) ➔ 클릭 시 `SCR-01 (P-0.0)` 이동
  - **중앙**: 1차 메뉴 (`1.0 척추 조끼 HW`, `2.0 시차 필터링`, `3.0 AI 대시보드`, `4.0 무료 체험/구독`, `5.0 데스크 케어`)
  - **우측**: [⚡ Latency: 12ms 상태 배지], [마이페이지 `[가정]`] ➔ `SCR-12`, [CTA: "GitHub 3개월 무료 시작"] ➔ `SCR-08`

### (2) 플로팅 스티키 바 (Floating Sticky Bar)
- **위치**: 화면 하단 고정 바 (#111827 / #0B0F17)
- **카피 및 버튼**:
  - *"💻 GitHub 로그인 시 AI 미니멀 케어 3개월 라이선스 즉시 무료 발급 [신용카드 등록 불필요]"*
  - `[GitHub 3개월 무료 시작]` ➔ `SCR-08 (P-4.3)` 모달 즉시 오픈

### (3) 글로벌 푸터 (FNB)
- **구성 요소**: 회사 정보, 오픈소스 라이선스(MIT), API 문서 링크, 30일 안심 무료 반품 규정, 고객센터.
