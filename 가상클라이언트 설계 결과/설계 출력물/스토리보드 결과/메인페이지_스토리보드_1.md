# SEUMIM(스밈) 메인페이지 스토리보드 (가상클라이언트 1: 박서준 총괄)

---

## 1. 스토리보드 개요 및 설계 기준

- **프로젝트명**: 스밈(SEUMIM) 통합형 스마트 홈케어 체형 교정 플랫폼 메인페이지 스토리보드
- **대상 화면**: `SCR-01` / `0.0 메인 랜딩페이지 (P-0.0)` 및 메인 직결 연계 모달 2종(`SCR-04`, `SCR-10`)
- **기획 총괄 / 가상클라이언트**: 박서준 (스밈 서비스 기획 총괄)
- **비즈니스 아키텍처**: HW 판매(3대 시그니처) + SW 구독(AI 미니멀 케어) + O2O 오프라인 동행센터 3중 선순환 모델
- **스토리보드 기술 원칙**:
  1. 메인페이지를 구성하는 모든 개별 섹션과 연계 모달을 **화면/섹션 1개당 1개의 정형화된 상세 표(Table)** 형식으로 작성
  2. 기획 의도, 헤드카피 및 서브카피, UI 요소, 레이아웃, 인터랙션, 상태별 화면(기본/로딩/빈상태/오류/완료), 반응형 정책을 누락 없이 명시
  3. 사이트맵(`P-0.0` ~ `P-9.2`), 서비스 흐름도(`ST-01` ~ `ST-92`), 화면 설계서(`SCR-01` ~ `SCR-14`)와의 100% 명칭 및 ID 일치성 유지

| **작동 방식 & 인터랙션** | • 메인/제품 페이지에서 선택한 제품/사이즈 정보가 자동 프리필(Prefill)되어 노출<br>• 필수 필드 미입력 상태에서 `[신청 완료]` 클릭 시 누락된 필드가 붉은색(`#EF4444`)으로 강조되며 포커스 이동<br>• 정상 입력 후 제출 시 ➔ 로딩 스피너 1초 후 "신청이 정상 완료되었습니다!" 토스트 및 마이페이지(`SCR-12`) 이동 |
| **연결 화면 & 경로** | `SCR-04 (P-2.4)` 정밀 사이즈 모달, `SCR-01 (P-0.0)` 메인 복귀, `SCR-12 (P-6.2)` 마이페이지 |
| **사용자 경로 (Journey)`** | `ST-06` ➔ `ST-06A` (최종 핵심 행동 완료) |
| **화면 상태별 UI** | • **기본**: 프리필된 제품/사이즈 및 빈 인풋 폼 노출<br>• **로딩**: `[신청 완료]` 버튼 내 로딩 스피너 동작 및 비활성화<br>• **오류(Error)**: 휴대폰 번호 형식 오류 시 "올바른 번호를 입력해 주세요" 오류 툴팁 표시<br>• **완료(Complete)**: 접수 번호 안내 및 마이페이지 이동 팝업 노출 |
| **반응형 레이아웃 기준** | • **데스크톱**: 580px 중앙 고정 모달<br>• **모바일**: 전체 화면 풀스크린 모달(Full-screen Modal) 전환 |
| **비고 및 기획 의도** | 복잡한 회원가입 절차 없이 1-Click에 준하는 간소화된 폼으로 이탈률을 최소화하고 전환율을 극대화 |

## 4. 데이터 유효성 검증 규칙 (Validation Matrix)

| 입력 필드 | 필수 여부 | 유효성 검증 기준 | 오류 발생 시 UI 동작 및 메시지 |
|:---|:---:|:---|:---|
| **체험 제품** | 필수 | 3개 제품 중 최소 1개 이상 선택 | 미선택 시 제품 선택 영역 붉은색 테두리 ("체험하실 제품을 선택해 주세요.") |
| **사이즈** | 필수 | Type 1 / Type 2 / Type 3 중 1개 선택 | 셀렉트 박스 미선택 시 경고 ("사이즈를 선택해 주세요.") |
| **신청자 이름** | 필수 | 한글/영문 2자 이상 20자 이하 | 인풋 테두리 `#EF4444` ("이름을 2자 이상 입력해 주세요.") |
| **휴대폰 번호** | 필수 | 10~11자리 숫자 (010, 011 등 정규식 일치) | 인풋 테두리 `#EF4444` ("올바른 휴대폰 번호를 입력해 주세요.") |
| **배송지 주소** | 필수 | 우편번호 검색 및 상세주소 1자 이상 | 상세주소 인풋 포커스 ("상세 주소를 입력해 주세요.") |
| **이용약관 동의** | 필수 | 체크박스 체크 필수 (`checked === true`) | 체크박스 흔들림(Shake) 효과 ("필수 약관에 동의해 주세요.") |

## 5. 설계 가정사항 모음 (`[가정]`)

1. **사전 신청 데이터 처리 (`SEC-M2`)**: 비회원 상태에서 30일 시착을 신청하더라도 입력된 휴대폰 번호를 기반으로 임시 계정 및 세션이 생성되어 마이페이지(`SCR-12`)에서 배송 및 반품 현황 조회가 가능한 것으로 가정함.
2. **O2O 동행센터 지도 연동 (`SEC-08`)**: 카카오맵/네이버 지도 API를 통해 사용자의 브라우저 위치 권한(GPS) 허용 시 가장 가까운 제휴 센터가 1순위로 자동 추천되는 정책을 가정함.
3. **스마트워치 UI 시연 (`SEC-06`)**: 실제 하드웨어가 연결되지 않은 웹 환경에서는 표준 기준 자세 데이터를 기반으로 게이지 및 링 애니메이션이 시뮬레이션으로 구동되는 것으로 가정함.
