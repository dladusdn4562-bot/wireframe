## 1. 개요 및 ST-01 ~ ST-14 전 14단계 상세 정의표

## 2. 3대 핵심 전환 여정 (Happy Path Detailed Flow)

### [Flow A] 15개 상품 탐색 ➔ 퀵뷰 ➔ 콕핏 사이즈 매칭 ➔ 30일 무료 시착 (Primary Path)
- **여정 단계**: `ST-01` ➔ `ST-02` ➔ `ST-03` ➔ `ST-04` ➔ `ST-05` ➔ `ST-06` ➔ `ST-07` ➔ `ST-08`
- **전환율 최적화 전략**: 4대 탭으로 15개 상품을 즉시 비교하고, 퀵뷰 모달과 100% 무료 반품 보증을 통해 구매 저항 제로화.

### [Flow B] 강남 e스포츠 콕핏 피팅 센터 1:1 시트 포지션 4단계 예약 (O2O Path)
- **여정 단계**: `ST-01` ➔ `ST-09` ➔ `ST-10` (Step 1~4) ➔ `ST-11` ➔ `ST-08`
- **전환율 최적화 전략**: 사용 장비(휠/페달/시트) 사전 입력을 통한 고밀도 맞춤 피팅 제공.

### [Flow C] AI 텔레메트리 3개월 무료 라이선스 구독 (Digital Care Path)
- **여정 단계**: `ST-01` ➔ `ST-12` ➔ `ST-11` ➔ `ST-08`
- **전환율 최적화 전략**: iRacing/ACC 연동 HUD 랩타임 비교 시연 후 Steam 1-Click 연동.

## 3. 5대 분기 및 예외 처리 (Exception & Branch Handling)
1. **상품 품절/재고 부족 분기**: 해당 카드의 [30일 시착] 버튼이 `[품절 - 재입고 알림 신청]`으로 자동 전환.
2. **입력 폼 유효성 에러 분기**: 연락처 자리수 오류 또는 배송지 누락 시 붉은색 테두리 하이라이트.
3. **센터 타임슬롯 마감 분기**: 선택한 날짜 마감 시 대기 예약 또는 타임슬롯 추천 팝업 표출.
4. **네트워크 통신 지연**: 5초 이상 응답 지연 시 "피트인 연결이 불안정합니다" 재시도 토스트 노출.
5. **유효하지 않은 URL 접근**: `SCR-13` 404 페이지 라우팅 후 메인 15개 상품 쇼케이스 유도.
