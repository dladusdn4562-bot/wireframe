## 1. 개요 및 ST-01 ~ ST-14 전 14단계 상세 정의표

본 문서는 사용자가 웹사이트에 첫 진입한 시점부터 15개 상품 탐색, 퀵뷰 스펙 확인, 사이즈 매칭, 30일 무료 시착 신청, 전국 35개 웰니스 센터 4단계 Wizard 예약, AI 바이오 모니터링 구독까지의 **전체 14단계 인터랙션과 프론트/백엔드 시스템 처리 로직, 분기 조건, 예외 처리**를 집대성한 최상위 단일 마스터 흐름도입니다.

## 2. 통합 3대 Happy Path 및 7대 분기/예외 처리

### [Flow A] 15개 상품 탐색 ➔ 퀵뷰 ➔ 사이즈 매칭 ➔ 30일 무료 시착 (Primary Conversion)
- `ST-01` ➔ `ST-02` ➔ `ST-03` ➔ `ST-04` ➔ `ST-05` ➔ `ST-06` ➔ `ST-07` ➔ `ST-08`
- **전환 전략**: 메인페이지 이탈 없이 4대 탭으로 15개 상품을 즉시 비교하고, 100% 무료 반품 보증을 통해 결제 및 구매 허들을 완전히 제거.

### [Flow B] 전국 웰니스 센터 1:1 3D 체형 스캔 4단계 예약 (O2O Conversion)
- `ST-01` ➔ `ST-09` ➔ `ST-10` (Step 1~4) ➔ `ST-11` ➔ `ST-08`
- **전환 전략**: 직업 작업 환경 사전 입력을 통해 1:1 맞춤형 체형 리셋 처방을 제공하여 오프라인 방문 만족도 극대화.

### [Flow C] AI 바이오 척추 데이터 케어 3개월 무료 라이선스 구독 (Digital SaaS Conversion)
- `ST-01` ➔ `ST-12` ➔ `ST-11` ➔ `ST-08`
- **전환 전략**: 실시간 자세 점수 HUD 게이지 시연 후 SNS 1-Click 연동으로 신속한 소프트웨어 활성화.

## 3. 7대 분기 및 예외 처리 로직 (Exception Handling Matrix)
1. **상품 품절/재고 부족 분기**: 해당 카드의 `[30일 시착]` 버튼이 `[품절 - 재입고 알림 신청]`으로 자동 전환.
2. **배송지/연락처 유효성 에러**: 전화번호 자리수 오류 또는 배송지 누락 시 붉은색 테두리 하이라이트 및 안내 툴팁 표출.
3. **센터 슬롯 마감 분기**: 선택한 날짜의 타임슬롯 마감 시 '대기 예약 접수' 또는 '인근 거점 센터 추천' 팝업 노출.
4. **네트워크 지연/타임아웃**: 5초 이상 API 응답 지연 시 "네트워크 연결이 불안정합니다. 다시 시도해주세요" 재시도 토스트 표시.
5. **IoT 센서 미페어링 분기**: 스마트 센서 미연결 상태일 경우 가상 시뮬레이션 모드로 대시보드 자동 전환.
6. **유효하지 않은 URL 접근**: `SCR-13` 404 페이지로 안전하게 라우팅 후 메인 쇼케이스 복귀 유도.
7. **정기 서버 점검**: `SCR-14` 점검 페이지 노출 및 비상 고객센터 연락망 제공.
