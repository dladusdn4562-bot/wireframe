# SEUMIM 브랜드 소개 전용 서비스 흐름도 (서비스_흐름도_91) - 바디럽 상품별 독립 스토리 모델

## 1. 서비스 흐름도 개요
- **문서 목적**: `가상클라이언트_91_스밈_바디럽형_상품별스토리_브랜드소개`의 요구사항을 반영하여, **바디럽(BODYLUV)형 [일상 공감 ➔ 4대 상품 라인별 독립 서사 ➔ 3D 단면 분해도 조작 ➔ 28종 쇼케이스 탐색 ➔ 30일 무료 시착(결제금액 0원)]** 마찰 제로 엔드-투-엔드 서비스 플로우를 정의한 명세서입니다.
- **핵심 설계 목표**:
  1. **바디럽형 공감 질문 인트로 진입**: 사용자의 일상 통증에 공감대를 형성하고 스토리 몰입 유도.
  2. **상단 서브 탭 & 스크롤 스파이(ScrollSpy)**: 관심 있는 상품 라인의 개발 서사로 즉시 점프.
  3. **상품별 3D 단면 분해도 인터랙션**: 0.1mm 센서 섬유 조직, 척추 탄성 프레임, 스마트 에어셀 조작.
  4. **30일 결제금액 0원 무료 시착**: 마찰 제로 바텀시트를 통한 1초 신청 완료.

## 3. 분기 조건 및 예외 처리 (Decision Logic & Exceptions)

1. **[분기 1] 상단 스토리 앵커 탭 클릭 vs 자유 스크롤**:
   - 탭 클릭 시: 해당 라인 섹션으로 즉시 스크롤 애니메이션(`window.scrollTo({behavior: 'smooth'})`) 실행 후 해당 탭 `active` 클래스 부여.
   - 자유 스크롤 시: Intersection Observer가 뷰포트 내 섹션을 감지하여 상단 탭을 실시간 동기화(ScrollSpy).
2. **[분기 2] 3D 단면 분해도 지원 여부**:
   - 하드웨어 가속 지원: WebGL 3D 캔버스 인터랙션 렌더링.
   - 저사양 기기/미지원: 고해상도 2D 레이어 분해 SVG 인포그래픽 자동 대체.
3. **[분기 3] 무료 시착 신청 시 기존 회원 vs 비회원**:
   - 기존 회원: 저장된 기본 배송지로 1초 즉시 신청 완료.
   - 비회원: 간편 휴대폰 인증 후 결제금액 0원 접수 완료.
