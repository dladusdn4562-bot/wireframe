# SEUMIM(SEUMIM Vet) 서비스 흐름도 명세서 (가상클라이언트 83: 수의사외과임상전문의)

## 1. 서비스 흐름 개요

본 문서는 **스밈(SEUMIM Vet) 통합형 스마트 홈케어 체형 교정 플랫폼(가상클라이언트 83: 수의사외과임상전문의)**의 사이트맵과 심층 분석 결과를 기반으로 설계된 서비스 흐름도(Service Flowchart) 명세서입니다.

스밈의 핵심 비즈니스 모델인 **[HW 판매(15종 에르고 컬렉션) + SW 구독(AI 바이오 데이터 케어) + O2O 오프라인 웰니스 센터 3중 선순환 모델]**을 완결성 있게 구현하기 위해, `image.png` 스타일의 브랜드 매니페스토 선언부터 3대 대표작 집중 조명, 15개 상품 탭 비교, 퀵뷰, 30일 시착 신청, 4단계 센터 예약, AI HUD 구독, 5대 예외 처리까지의 전 과정을 유기적으로 연결하였습니다.

```text
[서비스 기본 여정 구조]
브랜드 매니페스토 선언 ──> 대표 3종 집중 조명 ──> 15개 상품 탭 탐색 ──> 퀵뷰/사이즈 가이드 ──> 30일 시착 신청 / O2O 예약 ──> 완료
```

## 3. 핵심 정상 흐름 (Core Happy Path 3종)

### (1) Flow A: 하드웨어 30일 무료 시착 및 사전 신청 흐름 (Primary HW Conversion)
1. **탐색 (Discovery)**: 사용자가 `0.0 메인 랜딩페이지 (SCR-01)` 접속 후 `image.png` 스타일의 브랜드 매니페스토와 4대 자부심 지표(38g, 99.8%, 300+, 100%), 외과 수의사의 93.1%가 4시간 이상 연속 수술 시 경추 45도 굴곡으로 디스크 조기 퇴행 통계를 확인.
2. **대표작 확인 (Featured View)**: `SEC-02~04` 섹션에서 3대 시그니처 대표 상품(0.1mm 심리스 벳(Vet) 넥&숄더 밴드, 3D 에어로 메쉬 수의 외과 척추 정렬 조끼, 동물 수술 짝다리 방지 골반 에어셀 벨트)의 3D 단면도와 작동 원리를 집중 확인.
3. **15개 상품 탭 비교 (Selection)**: `SEC-06` 15개 상품 쇼케이스에서 4대 카테고리 탭(시그니처4, 케어4, 센서4, 직업ACC3)을 전환하며 동물병원 외과 수술 및 처치 전문 수의사 전용 에르고 ACC(수의 수술실 요추 만곡 에어 럼버 앵커, 미세 봉합 손목 중립 락 스트랩, 처치실 10시간 기립 체압 분산 힐 컵) 스펙 비교.
4. **퀵뷰 및 사이즈 확인 (Detail View)**: 관심 상품의 [🔍 퀵뷰] 클릭 ➔ 모달에서 3D 룩북 확인 ➔ 필요 시 `SCR-04` 정밀 사이즈 가이드를 통해 상의(95/100/105) 최적 사이즈 도출.
5. **핵심 행동 (Core Action)**: `SCR-10` 30일 무료 시착 모달 호출 ➔ 상품/사이즈 확인 ➔ 배송지 주소 입력 ➔ 100% 무료 반품 정책 동의 후 "무료 시착 신청 완료" 클릭.
6. **결과 확인 (Confirmation)**: 결제금액 0원 접수 완료 화면 노출 및 안심 배송 안내 SMS 발송.

### (2) Flow B: AI 바이오 데이터 케어 3개월 무료 라이선스 구독 흐름 (Digital SW Conversion)
1. **탐색 (Discovery)**: 메인페이지의 AI 데이터 케어 섹션 또는 GNB `3.0 AI 데이터 케어 (SCR-05)` 클릭 진입.
2. **시연 체험 (Interactive Demo)**: 실시간 척추 밸런스 HUD 대시보드에서 자세 점수(94.8점), 경추 각도(14.2°), 좌우 체압(50:50) 라이브 게이지 인터랙션 시연.
3. **상세 확인 (Detail View)**: 동물병원 외과 수술 및 처치 전문 수의사 맞춤 '앉은 자리 10초 미니멀 릴렉스 루틴' 및 무소음 촉각 햅틱 넛지 시스템 확인.
4. **핵심 행동 (Core Action)**: "3개월 무료 라이선스 받기" 클릭 ➔ `SCR-11` SNS 1-Click 간편 로그인 (카카오/네이버) ➔ 구독 라이선스 승인.
5. **결과 확인 (Confirmation)**: `SCR-12` 마이페이지로 이동하여 실시간 척추 데이터 대시보드 활성화 확인.

### (3) Flow C: 전국 35개 제휴 웰니스 센터 1회 무료 3D 체형 스캔 4단계 예약 흐름 (O2O Conversion)
1. **탐색 (Discovery)**: 메인페이지 웰니스 센터 배너 또는 GNB `4.0 웰니스 센터 (SCR-06)` 클릭 진입.
2. **지점 선택 (Selection)**: 위치 기반 지도 검색에서 가까운 제휴 센터 지점 및 전담 체형 교정 전문가 프로필 확인.
3. **4단계 Wizard 예약 진행 (`SCR-07`)**:
   - **Step 1 (지점 확인)**: 선택 지점 및 프로그램 확인.
   - **Step 2 (일시 선택)**: 실시간 잔여 슬롯 캘린더에서 희망 날짜/시간대 선택.
   - **Step 3 (직업 환경 입력)**: 동물병원 외과 수술 및 처치 전문 수의사 직업 특성 및 수술/처치대 90도 상체 숙임 자세 및 대형견 보정 시 상체 편측 하중 쏠림으로 인한 경추 및 요추 통증 통증 부위 체크.
   - **Step 4 (최종 동의 및 제출)**: 예약 정보 확인 및 동의 후 제출.
4. **결과 확인 (Confirmation)**: `SCR-08` 예약 완료 화면으로 이동하여 예약 번호, 방문 지도 확인 및 카카오톡 알림톡 수신.

## 4. 분기, 오류, 이탈, 재진입 흐름 (Branching & Exception Flows)

```text
[5대 분기 및 예외 대응 체계]
├─ 1. 로그인 세션 분기 (Auth Branch)
│  ├─ 로그인 상태 ➔ 즉시 AI 구독/시착/예약 접수 완료
│  └─ 비로그인 상태 ➔ SCR-11 간편 로그인 ➔ 인증 완료 후 직전 작업 단계로 자동 복귀 (Return URL)
│
├─ 2. 입력값 유효성 검증 오류 (Validation Error Branch)
│  ├─ 연락처 형식 오류 또는 배송지 주소 누락 시
│  └─ 오류 필드 붉은색 테두리 하이라이트 + 툴팁 노출 + 입력 데이터 100% 보존 상태로 포커스 이동
│
├─ 3. O2O 검색 결과 0건 분기 (Empty State Branch)
│  ├─ 해당 지역 제휴 센터 미존재 시
│  └─ "인접 추천 지점 안내" 및 "온라인 30일 무료 시착 우선 체험" 대체 CTA 자동 전환
│
├─ 4. 모달 닫기 및 단계 이탈 방지 (Cancellation Flow)
│  ├─ Wizard 진행 중 '이전' 클릭 ➔ 기존 입력값 유지하며 직전 Step 복귀
│  └─ 닫기(X) 또는 배경 클릭 ➔ "작성 중인 내용이 저장되지 않습니다" 컨펌 팝업 ➔ 안전한 모달 닫기
│
└─ 5. 시스템 및 비정상 접근 예외 (System Exception Flow)
   ├─ 잘못된 URL 접근 ➔ SCR-13 (9.1 404 Not Found) ➔ 메인페이지 복귀 CTA
   └─ 정기 서버 점검 ➔ SCR-14 (9.2 시스템 점검 안내) ➔ 점검 완료 예정 시간 안내
```
